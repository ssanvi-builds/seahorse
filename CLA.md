# Contributor License Agreement

Seahorse is an open standard, licensed under the Apache License, Version 2.0
(see [LICENSE](LICENSE)). To accept external contributions cleanly — and to keep
this project viable as an open standard for everyone, including commercial
adopters — we ask every first-time external contributor to agree to the terms
below before their first pull request is merged.

This agreement is adapted from the Apache Software Foundation's Individual
Contributor License Agreement (ICLA) template, simplified for a project managed
on GitHub.

## Why a CLA

The Apache-2.0 license of your contribution does most of the work already. What
the agreement adds on top:

- An explicit statement that the code you submit is yours to license, so the
  project never inherits unclear provenance.
- A patent grant covering your contributions, so no contributor (or their
  employer) can later assert patents against the standard.
- A durable record of who agreed to what, auditable by anyone.

## How to sign

Signing costs one comment. In your first pull request, add a comment containing:

```
I have read the CLA at CLA.md and agree to its terms — <legal name> (<github handle>)
```

Use your legal name (or the name your employer uses for you) — not a pseudonym —
and your GitHub handle. One signed PR covers all your future contributions.

Alternatively, email the contact address listed on the repository profile with
the same statement.

Signatures are recorded publicly in the pull request thread, so the record is
auditable by anyone without additional infrastructure.

## Scope of this agreement

- You sign once for all your present and future contributions to this project.
- The project maintainer (the repository owner) is the original author and does
  not sign this agreement.
- Maintainers will not merge an external pull request until it carries a valid
  signature.
